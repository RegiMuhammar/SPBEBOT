# Frontend

React + TypeScript + Vite frontend untuk SPBEBOT.

## Stack

- React
- Vite
- Tailwind CSS v4
- shadcn-style component setup
- Cytoscape.js untuk visualisasi knowledge graph

## Menjalankan

```bash
npm install
npm run dev
```

Secara default frontend akan memanggil API di:

```env
VITE_API_URL=http://127.0.0.1:8000/api/v1
```
